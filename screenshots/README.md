# TravelSafe — Travel Route Safety Assessment

TravelSafe is a travel safety web application that helps users explore routes and view safety-related information for their journeys.

## Features

- Route search using starting point and destination
- Route map and travel information
- Nearby police stations, hospitals and pharmacies
- Estimated travel safety score
