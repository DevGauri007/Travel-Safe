\# TravelSafe - Travel Route Safety Assessment



TravelSafe is a web application that helps users explore travel routes and view safety-related information.



\## Features

\- Search starting point and destination

\- View travel routes

\- Find nearby police stations, hospitals and pharmacies

\- View estimated travel safety scores



\## Technologies Used

\- Python

\- Flask

\- HTML, CSS and JavaScript

\- OpenStreetMap services



\## Note

Safety scores are estimates generated by the current project logic and do not guarantee actual safety.
